# 第001天：建立 C++17 学习工程

## 一、今日学习内容

1. 创建 GitHub 仓库
2. 克隆仓库到 Ubuntu 服务器
3. 创建 C++17 工程目录
4. 编写第一个 C++17 程序
5. 使用 G++ 编译并运行
6. 保存程序运行结果

## 二、学习到的知识

- main() 是 C++ 程序的入口
- #include 用于引入头文件
- std::cout 用于输出信息
- std::string_view 是 C++17 引入的字符串视图类型
- -std=c++17 用于指定编译标准
- -Wall -Wextra 用于开启常用编译警告

## 三、编译命令

g++ -std=c++17 -Wall -Wextra src/main.cpp -o build/hello

## 四、运行命令

./build/hello

## 五、程序输出

Hello, C++17!

## 六、今日总结

成功在 Ubuntu 服务器上建立 C++17 学习工程，
掌握了最基本的编译与运行方法。
