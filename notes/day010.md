# Day 010：Eigen 与二维坐标变换

## 一、学习目标

1. 理解世界坐标系和车辆坐标系
2. 学习 Eigen::Vector2d 和 Eigen::Matrix2d
3. 实现车辆坐标到世界坐标的转换
4. 实现世界坐标到车辆坐标的转换
5. 验证逆变换的正确性

## 二、核心公式

车辆坐标 -> 世界坐标：

P_world = R * P_local + T

世界坐标 -> 车辆坐标：

P_local = R.transpose() * (P_world - T)

其中 R 为旋转矩阵，T 为车辆位置。

## 四、学习总结

1. 车辆局部坐标需要经过旋转和平移才能得到世界坐标。
2. 旋转矩阵的转置等于它的逆矩阵。
3. 浮点数计算可能存在极小误差。
4. 编译警告提示存在潜在代码问题，应及时检查。

## 五、自动驾驶应用

坐标变换用于将车辆局部感知到的障碍物位置
转换到世界坐标系，也用于局部轨迹规划和路径跟踪。
