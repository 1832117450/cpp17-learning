## 二、核心知识总结

### 1. 引用与 const
引用可以直接操作原对象，不需要复制。
const 引用不允许通过引用修改对象。

### 2. vector
vector 可以动态存储数据。
访问元素前需要检查容器是否为空以及索引是否有效。

### 3. RAII
RAII 将资源管理与对象生命周期绑定。
unique_ptr 可以自动管理所拥有的动态对象。

### 4. 工程模块化
include 存放接口声明。
src 存放功能实现。
tests 存放测试。
planning_core 用于组织可复用的核心功能。
