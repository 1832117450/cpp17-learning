# 第019天：PID速度控制

## 一、学习目标

1. 理解P、I、D三项的作用
2. 实现C++17车辆纵向速度控制器
3. 比较P、PI、PID控制效果
4. 通过仿真理解稳态误差、超调和积分饱和

## 二、控制原理

速度误差：

e = target_speed - actual_speed

PID控制公式：

u = Kp * e + Ki * integral(e) + Kd * derivative(e)

P：比例控制，根据当前误差进行调整。
I：积分控制，累积历史误差，帮助消除稳态误差。
D：微分控制，根据变化趋势提供阻尼作用。

本实验采用实际速度的负导数作为D项，
避免目标速度阶跃引起微分冲击。

## 三、车辆模型

采用简化纵向动力学：

actual_acc = control - 0.1 * speed

speed_next = speed + actual_acc * dt

时间步长：dt = 0.1 s
目标速度：第1秒从0跳变为10 m/s
加速度范围：[-3, 2] m/s^2

## 四、实验结果

| 指标 | P | PI | PID |
|---|---|---|---|
| Kp | 0.5 | 0.5 | 0.5 |
| Ki | 0 | 0.2 | 0.2 |
| Kd | 0 | 0 | 0.3 |
| 12秒绝对误差(m/s) | 1.690 | 0.336 | 0.634 |
| 最大超调(m/s) | 0.000 | 0.345 | 0.644 |
| IAE(m) | 40.366 | 32.022 | 32.714 |

IAE统计区间为1至12秒。

## 五、实验结论

1. P控制器能够跟踪目标速度，但存在稳态误差。
2. 增大Kp可以减小本实验的稳态误差。
3. I项可以改善稳态跟踪，但可能引入超调。
4. D项可以提供阻尼，但需要与P、I共同调参。
5. 本次实验中，PI的跟踪表现优于所测试的PID。
6. 12秒时的误差不等于最终稳态误差。
