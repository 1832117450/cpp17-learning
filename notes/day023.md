# 第023天：LQR中的Q与R

## 一、今日学习内容

1. 理解LQR的基本思想
2. 理解状态误差代价和控制代价
3. 理解Q、R矩阵的作用
4. 理解反馈增益K的意义
5. 使用C++17验证Q、R权重变化

## 二、核心公式

线性系统：
x(k+1) = A*x(k) + B*u(k)

LQR代价函数：
J = sum(x^T*Q*x + u^T*R*u)

反馈控制：
u = -K*x

## 三、简化一步优化实验

误差更新：
e_next = e + u

代价函数：
J = q*e_next^2 + r*u^2

最优控制：
u = -K*e
K = q/(q+r)

实验结果：

Q=1, R=1: K=0.5, u=1.0, 下一误差=-1.0
Q=9, R=1: K=0.9, u=1.8, 下一误差=-0.2
Q=1, R=9: K=0.1, u=0.2, 下一误差=-1.8

## 四、今日理解

1. A、B描述系统运动规律。
2. Q衡量状态误差代价。
3. R衡量控制输入代价。
4. 增大Q通常会使控制更重视减小误差。
5. 增大R通常会使控制输入更加保守。
6. K是反馈增益，完整LQR可通过Riccati方程求解。
7. 今天的代码是一步优化示例，并非完整LQR。

## 五、今日总结

已理解LQR中Q、R的基本作用，
并通过C++17实验验证不同权重对控制输入的影响。
