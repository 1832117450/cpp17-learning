## 三、编译与运行命令

配置工程：
cmake -S . -B build

编译工程：
cmake --build build

运行测试：
cd build
ctest --output-on-failure

## 五、知识总结

1. g++ 是 C++ 编译器。
2. CMake 用于管理工程构建。
3. GoogleTest 用于验证函数行为。
4. CTest 用于统一执行测试程序。
5. 单元测试可以帮助发现计算错误与边界问题。
6. 测试通过不代表函数在所有情况下都正确。
