# 第003天：STL与轨迹容器

## 一、今天学习的内容

1. std::vector：动态数组，保存轨迹点。
2. std::array：固定大小数组，保存二维坐标。
3. std::optional：表示数据可能不存在。
4. const auto&：只读引用，避免不必要的复制。

## 二、完成的编程任务

定义 TrajectoryPoint 结构体，包含：
- x：横坐标
- y：纵坐标
- speed：速度

使用 vector 保存并打印10个轨迹点。

使用 optional 处理不存在的轨迹点。

使用 empty() 检查空轨迹。

## 三、重要知识

vector可以动态增加和删除元素。

array的元素数量固定。

容器索引从0开始。

const引用可以防止通过引用意外修改数据。

## 四、自动驾驶应用

自动驾驶规划器需要保存一系列轨迹点。

vector适合存储长度可能变化的轨迹。

optional可以明确表示轨迹点获取失败。

./build/day03

理解了STL容器的基本用途，
