# 第024天：LQR轨迹跟踪实验

## 一、今日学习内容

1. 理解LQR横向跟踪的误差状态
2. 理解前馈控制与反馈控制
3. 运行PythonRobotics原始LQR示例
4. 修改Q矩阵中的横向误差权重
5. 对比两组轨迹的RMSE

## 二、核心公式

横向控制：
delta = delta_ff + delta_fb

前馈：
delta_ff = atan(L * kappa)

反馈：
delta_fb = -K * x

其中：
K为LQR反馈增益。
x为四维跟踪误差状态。

## 三、实验设置

参考算法：PythonRobotics LQR Steering Control

实验一：
Q = diag(1,1,1,1)
R = 1

实验二：
Q = diag(5,1,1,1)
R = 1

其他仿真条件保持一致。

## 四、实验结果

原始权重：
RMSE = 0.1112 m
记录步数 = 177
成功到达目标

修改权重：
RMSE = 0.0813 m
记录步数 = 176
成功到达目标

RMSE相对下降约26.9%。

注：RMSE使用车辆到最近参考离散采样点的距离计算。

## 五、实验分析

提高横向位置误差权重后，
当前场景下轨迹距离RMSE明显下降。

这说明Q矩阵可以影响LQR控制器对不同误差的重视程度。

但不能据此断言所有道路上增大Q都会改善性能。

当前尚未分析控制输入变化率及控制舒适性。

## 六、今日总结

1. 前馈控制根据道路曲率提前提供转向。
2. 反馈控制根据跟踪误差修正转向。
3. LQR利用A、B、Q、R计算反馈增益K。
4. Q矩阵可以改变控制器对各状态误差的重视程度。
5. 参数调节的效果需要通过实际闭环实验验证。
